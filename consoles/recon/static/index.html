Recon OSINT

Paste a username, email, domain, IP, ASN, Discord ID, phone number, file hash, crypto address, or MAC address. Recon auto-detects the type and runs live passive lookups, including infostealer breach intel on people and domains. Names/companies get a Wikipedia summary; everything else (images, coordinates) gets curated pivot links and dork queries instead. Passive, public sources only.

Subdomain takeover check

Follows each name's CNAME chain and flags any that point at a third-party service with a dangling / unclaimed resource — the classic subdomain-takeover setup. Passive: a CNAME lookup and one GET per name. Enter a single host, or paste several (comma / space / newline separated — e.g. the subdomains a domain scan turned up).
