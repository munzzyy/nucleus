Redcell offensive

The pentest kit — tool inventory, authorized runners, and a command builder for everything too aggressive to run from here. Authorized use only: your own systems, or written-scope engagements/labs/CTFs.

Authorization required gate

Every run on this page is gated server-side. Nothing executes without this box checked, and the gate can't be bypassed from the browser.

Safe runner

Fixed argv templates — your target fills exactly one slot. Any other choice you make (scan profile, tags, wordlist) is validated against a server-side list; only the looked-up fixed value ever reaches the command.

Expert run gate

      
Run any installed tool from your kit with your own arguments. Arguments are split into a
        real argv and executed directly — never through a shell, so nothing can break out. Only your
        pentest tools are runnable here (not arbitrary system commands). You own the target choice — same as
        your terminal, so only point it at what you're authorized to test.
